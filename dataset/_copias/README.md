# _copias/: quarentena com motivo

Aqui vive copia que **nao conta duas vezes**, sempre com o motivo no nome ou no registro:

- `duplicatas/` copia byte-identica (mesmo sha256) de um arquivo do bloco canonico. Continua no repo
  para nao sumir do historico, mas conta uma vez so.
- `rig-rotulado-bad-81/` os mesmos 81 frames de `nosso/rig/` com o rotulo antigo (errado), guardados
  para auditoria da correcao de rotulo.
- `contaminacao-mvtec/` imagens que tambem existem em `benchmark/mvtec/`.
- `copia-origem-rig/`, `copia-dataset-one-class/`, `duvidas/` copias de conteudo.

Regra: copia entra aqui **com o motivo escrito**, nunca como "arquivo extra".
