# Envelope de referência da Esteira B

Este arquivo registra valores genéricos do relatório fornecido para permitir um modelo preliminar de envelope. Não representa a mini-esteira real e não deve ser usado para fabricação, dimensionamento de clamp, datums, carga ou calibração.

Os valores `reference_placeholder` são apenas geometria de trabalho e devem ser substituídos por medições G0. A interface real, furos, datums, massa, CG, dinâmica e temperatura permanecem BLOCKED.

Próximo uso permitido: gerar um mock-up visual e verificar se o pipeline CAD aceita parâmetros intervalares. Próximo uso proibido: imprimir suporte estrutural ou montar câmera real.
