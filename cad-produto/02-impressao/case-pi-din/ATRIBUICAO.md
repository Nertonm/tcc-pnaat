
O mesmo modelo está publicado no Printables 660057, listado lá com o autor alec,
e essa página declara que é remix de "Raspberry Pi DIN Rail Case", de mdkendall.
O PDF desta pasta veio dessa publicação.

## Arquivos

```
pi5-din-topside.stl                       face da case
pi5-din-bottom-side.stl                   base, com o encaixe do trilho DIN

autor-readme.txt, autor-license.txt       arquivos do autor, como baixados
```

## Atenção

A licença ShareAlike é copyleft. A base do trilho deste projeto deriva de um
modelo com cláusula NonCommercial, e a case não tem essa cláusula. Se as peças
forem distribuídas juntas como um conjunto, a cláusula NonCommercial se estende
ao conjunto. A decisão precisa ser tomada antes de publicar.

A atribuição completa das referências de terceiro está em `../../ATRIBUICOES.md`.
